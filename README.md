# English Kids — GitHub Pages v31 FIXED

Эта версия специально сделана для простого GitHub Pages.

## Главное отличие
Все картинки уже упакованы внутрь файла `image-assets.js`. Папку `assets` загружать НЕ нужно.

## Что загрузить в репозиторий
Удалите старые файлы сайта или замените их и загрузите в корень репозитория ВСЕ файлы из этой папки:

- index.html
- 404.html
- app.js
- content.js
- styles.css
- image-assets.js  ← здесь все картинки
- .nojekyll

`image-assets.js` около 12 МБ, то есть укладывается в лимит загрузки GitHub через браузер.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root).
