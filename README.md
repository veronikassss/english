# English Kids — GitHub Pages

Эта версия готова к публикации как обычный статический сайт на GitHub Pages.

## Как выложить сайт

1. Создай новый репозиторий на GitHub, например `english-kids`.
2. Распакуй архив и загрузи **всё содержимое этой папки** в корень репозитория:
   - `index.html`
   - `app.js`
   - `content.js`
   - `styles.css`
   - папку `assets`
   - `.nojekyll`
3. На GitHub открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Нажми **Save**.
6. Через некоторое время GitHub покажет ссылку вида:
   `https://USERNAME.github.io/english-kids/`

Пользователям не нужно открывать `index.html`: GitHub Pages открывает его автоматически по ссылке сайта.

## Важно про прогресс

Сейчас прогресс ребёнка хранится в `localStorage` браузера. Поэтому:
- у каждого устройства/браузера свой прогресс;
- регистрация не нужна;
- если очистить данные браузера, прогресс сбросится.

Это подходит для текущего MVP. Позже можно подключить базу данных и аккаунты.
