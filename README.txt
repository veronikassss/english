English Kids static prototype — v12 Zoo Guide

Как открыть:
1. Распакуйте архив.
2. Откройте файл index.html двойным кликом в Chrome или Edge.
3. Если виден старый прогресс, нажмите «Сбросить прогресс».

Эта версия без npm и Node.js. Она нужна для просмотра и правок контента.
